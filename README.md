# STATUS SAFI — Modern Glass (English)

Upload these four files directly into the root of your GitHub Pages repository, replacing the existing files: index.html, style.css, app.js and README.md. Commit the changes and open the site in Safari. If an old version remains cached, refresh or use a private tab.

This build improves text contrast and adds clear timeouts/messages for video-engine download and startup, so the interface no longer stays at 10% indefinitely without an explanation. It uses the single-thread FFmpeg.wasm core for mobile-browser compatibility. Videos over 60 seconds are automatically split into consecutive 60-second parts. Photos are shared as their original file without resizing or recompression by STATUS SAFI. The home screen contains only Enhance Video and Enhance Photo. Copyright remains at the bottom.

Video processing is local and requires internet on first use. Keep Safari open. Mobile browsers have memory limits; very large videos may not process. WhatsApp may recompress media; send photos as Document when possible to preserve quality.
